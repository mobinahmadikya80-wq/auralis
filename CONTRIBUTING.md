# 🤝 Contributing & Future Expansion Roadmap

Thank you for your interest in contributing to **Auralis** — the open educational platform for audiology and hearing science.

---

## 🗺️ Future Feature Roadmap

Below are planned module expansions for future development phases:

### Phase 1: Real-Time High-Frequency Tympanometry Engine
- Multi-component 1000 Hz probe tone tympanometry for infant middle ear assessment.
- Interactive Y-B-G admittance component decomposition charts.

### Phase 2: WebGL 3D Cochlear Hair Cell Simulation
- Shader-based 3D animation of inner and outer hair cell stereocilia deflection under acoustic pressure waves.
- Simulation of aminoglycoside ototoxicity and acoustic trauma damage patterns.

### Phase 3: Real-Ear Measurement (REM) Probe Microphone Simulator
- Simulated REUR, REAR, REIG, and RECD insertion loss curves across pediatric and adult ear canals.
- Matching target curves for NAL-NL2 and DSL v5.0 fitting formulas.

### Phase 4: Audio Chirp & Speech Stimulus Audio Synthesizer
- Web Audio API integration generating calibrated CE-Chirp, Tone Burst, and Warble Tone acoustic stimuli directly in the browser.

## 🛠️ How to Contribute

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/new-audiometry-calculator
   ```
3. **Commit Your Changes**: Follow clear commit message conventions (`feat:`, `fix:`, `docs:`, `style:`).
4. **Submit a Pull Request**: Ensure all linting and build checks pass (`npm run lint && npm run build`).
